`mkpages` turns a plain Markdown folder tree into a small Jekyll source tree that GitHub Pages can publish without forcing the repository into a Jekyll-first authoring model.

It is aimed at documentation sites and small content-driven projects where the structure should stay obvious, Git should remain the source of truth, and the build step should stay boring.
