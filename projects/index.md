## Projects

A small set of tools and experiments around Python workflows, packaging, filesystem behavior, and release automation.

- [bnbnotify](/projects/bnbnotify/): Booking Notifications & Turnover Coordination
- [cropbox](/projects/cropbox/): Lightweight media crop and trim tool
- [distman](/projects/distman/): Versioned file distribution for production pipelines and packaged artifacts.
- [envstack](/projects/envstack/): Layered environment configuration for Python and shell-based workflows.
- [hashio](/projects/hashio/): Custom file and directory checksum and verification tool
- [mkpages](/projects/mkpages/): Generate Jekyll source trees from Markdown folder structures
- [pathbase](/projects/pathbase/): Structured filesystem path templates for Python
- [pyseq](/projects/pyseq/): Filesystem sequence utilities for media, VFX, and automation workflows.
- [snapfs](/projects/snapfs/): Snapshot-oriented filesystem ideas for reproducible working sets and experiments.
- [subfork](/projects/subfork/): Subfork is the easiest way to prototype, build, and share micro web applications
- [sview](/projects/sview/): Sequence-aware filesystem browser
