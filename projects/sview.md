`sview` is a sequence-aware filesystem browser built for the kinds of directory structures that show up in media, rendering, and automation-heavy workflows.

The project is centered on faster inspection of numbered files and sequence-oriented folders, with an emphasis on making dense filesystem state easier to navigate.
